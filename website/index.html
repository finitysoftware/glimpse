GOOD TO KNOW

Small details.
Clear answers.

What you need to know before
sharing your first link.

What is Glimpse?

Glimpse is a space for sharing and exploring private GitHub and GitLab repositories. Each account connects its own GitHub or GitLab token and manages its own links, while visitors follow a link to browse permitted content in a simple web interface.

Does Glimpse work with GitLab?

Yes. Connect GitLab.com or your own self-managed GitLab instance with a read_api token, alongside GitHub or on its own. Projects from both platforms appear in one list, and you can filter them by platform.

Do visitors need a GitHub or GitLab account?

No. An active access link is all they need. Visitors can browse permitted files and branches directly in their browser, without signing in to GitHub or GitLab or installing tools.

How do I share a private GitHub repository without adding a collaborator?

Connect your GitHub token in Glimpse, create an access link for the repository and send it. The visitor opens the link in a browser and reads the code without a GitHub account or a collaborator invitation. You can revoke the link at any time, and the same works for GitLab projects.

Can anyone change my code?

Access through Glimpse is read-only: visitors cannot modify the repository or push commits. Anyone who can view content can also copy it, so only share links with people you trust.

How do I control the scope and duration of access?

Choose a name, expiry date, allowed branches and history permissions for each link. Revoke a link or temporarily pause sharing for the entire repository. Expired or revoked links no longer open the content.

Can I share only one branch of a private repository?

Yes. Each link lists the branches it may open, and you can also limit which files each branch shows. Other branches stay hidden, and new branches appear only after you allow them.

Does Glimpse clone my repository?

No. Content is read through the GitHub or GitLab API, with a limited cache for faster browsing. Your tokens stay on the server and are never passed to visitors.
