# Glimpse user manual

This manual explains how to work with Glimpse, from signing in and connecting GitHub or GitLab to sharing a repository
through an access link, and how visitors and administrators see it. Every chapter has screenshots of the real
application.

## Chapters

1. [Signing in and your account](01-signing-in.md) - signing in, the sidebar, changing your password and signing out
2. [Connections](02-connections.md) - GitHub and GitLab tokens, connection checks, disconnecting and the preview cache
3. [Repositories](03-repositories.md) - the repository list, filtering by name and platform, and paging
4. [Browsing files](04-browsing-files.md) - the repository page, folders and files, the project tree, search and branches
5. [History](05-history.md) - commits, changed files and diffs, merge commits, file history and older revisions
6. [File visibility](06-file-visibility.md) - choosing which files of a branch visitors can open
7. [Access links](07-access-links.md) - creating, showing, editing, revoking and deleting links, and turning sharing off
8. [The visitor view](08-visitor-view.md) - what people who open a link see and can do
9. [The admin panel](09-admin-panel.md) - admin sign-in, the dashboard and the admin account
10. [Users and links in the admin panel](10-admin-users-and-links.md) - adding and editing accounts, tokens, and every access link

## About the screenshots

The screenshots show Glimpse with a set of example repositories and accounts. All names, people, addresses and
repositories in them are made up.
